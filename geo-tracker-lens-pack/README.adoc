== Build

Run from this project directory.

[source,bash]
----
./gradlew clean build
----

== Publishing

This project publishes to Maven Central through JReleaser.
The staged repository is written to `build/staging-deploy` before deployment.

[source,bash]
----
./gradlew publishMavenJavaPublicationToStagingDeployRepository
./gradlew jreleaserDeploy
----

== Adding the Dependency

The pack will be published to Maven Central, so no repository declaration or authentication is required.
Add it to `lensStyle` in a project that already applies the Tracker Lens plugin.

.Gradle (Kotlin DSL)
[source,kotlin]
----
dependencies {
    lensStyle("com.arc-e-tect:geo-tracker-lens-pack:0.0.1")
}
----

.Gradle (Groovy DSL)
[source,groovy]
----
dependencies {
    lensStyle 'com.arc-e-tect:geo-tracker-lens-pack:0.0.1'
}
----
